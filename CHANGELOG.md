# Changelog

## [Обновление] Структурированная форма для генерации сюжета

### Что изменилось:

**До:** Пользователь вводил свободный текст в одно поле

**После:** Пользователь заполняет структурированную форму с параметрами:

#### Поля формы:
1. **Тема / Ниша** - Основная тематика (авто, мода, технологии и т.д.)
2. **Целевая аудитория** - Кто будет смотреть (мужчины 25-35, молодежь и т.д.)
3. **Настроение / Стиль** - Выбор из списка (драматично, весело, мотивационно и т.д.)
4. **Обязательные элементы** - Что должно быть в кадре
5. **Длительность** - 5 или 10 секунд
6. **Целевые платформы** - Instagram, TikTok, YouTube (можно выбрать несколько)
7. **Дополнительные указания** - Свободный текст для деталей

### Преимущества:

✅ **Более точная генерация** - AI получает структурированные данные вместо свободного текста
✅ **Лучший контроль** - Пользователь явно задает все параметры
✅ **Консистентность** - Все проекты создаются по одному шаблону
✅ **Адаптация под платформу** - AI сразу знает где будет публикация

### Технические изменения:

**Backend:**
- `GenerateStoryRequest` schema расширена с новыми полями
- `openai_service.generate_story()` принимает структурированные параметры
- Улучшенный промпт для ChatGPT с вводными параметрами

**Frontend:**
- Новый компонент `StoryForm` с полноценной формой
- Обновлен API клиент для передачи новых параметров
- Улучшен UI/UX первого этапа

### Пример использования:

```typescript
// Раньше:
{ custom_input: "сделай видео про авто для молодежи" }

// Теперь:
{
  theme: "автомобили",
  target_audience: "мужчины 20-30, автолюбители",
  mood: "Эпично",
  key_elements: "спорткар, ночной город, неоновые огни",
  duration: 5,
  platforms: ["instagram", "tiktok"],
  additional_notes: "в стиле Need for Speed"
}
```

Это дает AI намного больше контекста для создания идеального вирального контента!
