# Project Goals

**Период:** 3 месяца (февраль — апрель 2026)
**Тип:** Proof of Concept — go/no-go по результатам

---

## North Star

**10 000 000 органических просмотров на YouTube** на одном канале за 3 месяца.
Стоимость опубликованной единицы контента **≤ $4** (только генерация, включая брак).

---

## Ключевые метрики

| Метрика | Target | Как считаем |
|---------|--------|-------------|
| YouTube views (total) | 10 000 000 | Суммарно за 3 месяца, один канал |
| Видео/месяц | 60 | Опубликованных (прошедших модерацию) |
| Cost per published unit | ≤ $4.00 | (total API spend) / (published videos) |
| Cost per generation attempt | ≤ $2.60 | $4 × 0.65 (при 35% браке) |
| Reject rate (брак) | ≤ 35% | Не прошедших модерацию / всего сгенерированных |

## Go/No-Go критерии (конец 3 месяца)

**Go если:**
- ≥ 5M views (50% от target) — тренд растёт
- Cost per unit ≤ $4
- Есть хотя бы 2 "топ" видео (>500K views)
- Канал не забанен / не демонетизирован

**No-Go если:**
- < 2M views — алгоритм не подхватывает контент
- Cost per unit > $6 — экономика не сходится
- Канал забанен / shadowban
