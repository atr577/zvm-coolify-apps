# Agent Producer

## Что это
Агент получает концепт канала (строка из таблицы идей) и автономно генерит неограниченное количество уникальных видео, используя набор инструментов.

## Три фазы

```
Строка из таблицы идей
    │
    ▼
[Phase 1] RESEARCH ──► Production Config ──► Human Review
    │                                            │
    │                    ┌───────────────────────┘
    ▼                    ▼
[Phase 2] PRODUCTION ──► eval loop ──► готовые видео
    │
    ▼
[Phase 3] PUBLISH ──► YouTube/TikTok (потом)
```

| Фаза | Что делает | Спека | Стоимость |
|------|-----------|-------|-----------|
| **Research** | Ресерч ниши, конкурентов, подбор моделей → Production Config | [SPEC-research-agent.md](../specs/SPEC-research-agent.md) | ~$0.05-0.10/концепт |
| **Production** | Генерация контента по config через 7 eval gates | [SPEC-agent-eval-loop.md](../specs/SPEC-agent-eval-loop.md) | ~$1.83/видео |
| **Publish** | Публикация + метрики + feedback loop | TBD | — |

**Research** выполняется один раз на концепт, **Production** — многократно (60+ видео из одного config).

Human review между Research и Production — человек валидирует config перед тем как агент потратит деньги на генерации.

## Вход
Строка из Google Sheets таблицы идей (`1PuluIu5bsG_-XnrXp_kaEGWdbecHkiNdnjkXYcMSinE`):

| Поле | Описание |
|------|----------|
| Название | Идея канала |
| Суть идеи | Детализация контента |
| Хук ЦПК | Что в первых 1-2 секундах (гипотеза) |
| Хук ПВС | Что заставляет пересмотреть (гипотеза) |
| Вовлечение | CTA, комменты, интерактив (гипотеза) |
| Пример | Референс YouTube (опционально) |
| ДЛ | Целевая длительность |

Поля "Хук ЦПК", "Хук ПВС", "Вовлечение" — гипотезы авторов. Research agent валидирует и расширяет их, не копирует слепо.

## Выход
Готовые видео — агент сам решает как их собрать, используя tools и knowledge base.

## Channel Definition (структура)

```yaml
channel:
  name: "Смешивание красок"
  description: "Загадка какой цвет получится при смешивании"

creative_instruction: |
  Придумай два контрастных цвета и реальный результат их смешивания.
  Опиши как выглядит процесс смешивания.
  Каждый раз — новая пара цветов, новый визуальный стиль смешивания.

hook_pattern: "Два ярких контрастных цвета крупным планом"
engagement_pattern: "Вопрос зрителю → ответ в конце → комменты"

visual_rules:
  - "чёрный фон, контрастные яркие цвета"
  - "overhead camera"
  - "studio lighting"

target_duration: 10s
```

**Что НЕ указывается в definition:**
- Конкретные модели — агент выбирает сам
- Структура сцен — агент решает сколько шотов и какие
- Тип pipeline — нет типов, есть инструменты
- Overlay/audio — агент решает на основе engagement_pattern

## Разбор трёх концептов

### 1. Смешивание красок

| Параметр | Значение |
|----------|----------|
| Тип контента | Залипательный + вопрос |
| Что варьируется | Пара цветов, способ смешивания |
| Ожидаемая структура | Показать цвета → смешать → результат (агент решает детали) |
| Image generation | Каждый ролик (новые цвета) |
| Video generation | Да — жидкости должны двигаться |
| Text overlay | "Какой цвет?" → ответ |
| Audio | Ambient/satisfying звук |
| Хук | Два ярких цвета крупно |
| Вовлечение | "Угадал?" → комменты |
| Creative instruction | "Придумай два контрастных цвета и реальный результат их смешивания. Опиши как выглядит процесс смешивания." |

### 2. Космические катастрофы

| Параметр | Значение |
|----------|----------|
| Тип контента | Завораживающий визуал |
| Что варьируется | Космический объект, сценарий столкновения |
| Ожидаемая структура | Показать масштаб → катастрофа → последствия (агент решает детали) |
| Image generation | Каждый ролик (новая планета/объект) |
| Video generation | Да — главный контент это motion |
| Text overlay | Название объекта, масштаб |
| Audio | Эпичная музыка/SFX |
| Хук | Масштабное сравнение "Земля vs..." |
| Вовлечение | "Какую катастрофу представляешь?" |
| Creative instruction | "Выбери космический объект и опиши что произойдёт если он заменит/столкнётся с Землёй/Солнцем. Масштаб должен впечатлять." |

### 3. Найди отличия

| Параметр | Значение |
|----------|----------|
| Тип контента | Интерактив/пауза |
| Что варьируется | Картинка, количество и сложность отличий |
| Ожидаемая структура | Показать 2 картинки → таймер → ответ (агент решает детали) |
| Image generation | Базовая картинка → копия с отличиями через img2img edit |
| Video generation | Нет — статичные картинки + таймер |
| Text overlay | "Найди 5 отличий", таймер, ответы |
| Audio | Тикающий таймер |
| Хук | Яркая картинка + "5 отличий" |
| Вовлечение | "С какой попытки нашёл все?" |
| Creative instruction | "Создай детальную картинку и её копию с 5 небольшими отличиями. 4 средней сложности, 1 очень сложное." |

## Инструменты агента

Агент — не фиксированный pipeline, а LangGraph agent с набором tools. Сам решает какие инструменты использовать и в каком порядке.

| Tool | Что делает | Когда использовать |
|------|-----------|-------------------|
| `generate_image` | Text-to-image | Старт-кадр, фон, объекты |
| `edit_image` | Image-to-image editing | Вариации, отличия, трансформации между кадрами |
| `generate_video` | Image-to-video (single/multi-shot) | Анимация, motion, физика |
| `compose_static` | ffmpeg — склейка картинок в видео | Статичный контент (ребусы, отличия) |
| `add_overlay` | Текст/таймер/стикеры поверх видео | Вопросы, CTA, ответы |
| `add_audio` | Музыка/SFX/TTS/ambient | Звуковое оформление |
| `evaluate` | Vision model оценивает результат | QA перед публикацией |

### Пример: как агент собирает "Смешивание красок"

```
1. LLM думает: "красный + синий → фиолетовый"
2. generate_image → два потока краски на чёрном фоне
3. generate_video (multi-shot 3+5+2s) → краски текут, сливаются, результат
4. add_overlay → "Какой цвет получится?" (0-3s), "Фиолетовый!" (8-10s)
5. add_audio → ambient satisfying sound
6. evaluate → проверка качества
```

### Пример: как агент собирает "Найди отличия"

```
1. LLM думает: "детальная кухня, 5 отличий: нож, чашка, цвет стены..."
2. generate_image → базовая картинка кухни
3. edit_image × 5 → копия с 5 отличиями
4. compose_static → две картинки рядом, 15s видео
5. add_overlay → "Найди 5 отличий!" (0s), таймер (0-10s), ответы (10-15s)
6. add_audio → тикающий таймер
7. evaluate → проверка
```

### Знания агента о моделях

Агент выбирает модели на основе knowledge base, а не хардкода:

**Video:** Kling O3 (continuity), Kling v3 (физика), Grok/Wan (бюджет), Veo 3.1 (lip sync)
**Image:** Nano Banana (реализм), Flux Kontext (editing), Recraft V3 (text), Seedream (бюджет)

## Flow агента

```
1. UNDERSTAND CHANNEL
   Строка из таблицы → channel definition
   Если есть референс — разобрать на кадры, понять стиль и timing

2. GENERATE VIDEO (автономный цикл)
   a. LLM с creative_instruction → конкретная вариация (цвета, объекты, сюжет)
   b. Агент сам решает какие tools вызвать и в каком порядке
   c. evaluate → проверка качества
   d. Если плохо → retry с новой вариацией или другим подходом (max 2 retry)
   e. Если ок → сохранить .mp4

3. LEARN
   Результаты evaluate + фидбек → обновление стратегии выбора tools/моделей
```

Нет отдельного Executor — агент сам и планирует, и исполняет.

## Технологии
- **LangGraph** — orchestration, ReAct agent с tools
- **LLM** — creative decisions, prompt generation, evaluation
- **fal.ai** — image + video generation (все модели через единый API)
- **ffmpeg** — post-processing, concat, overlay, audio
- **Knowledge base** — docs/knowledge/ (prompting rules, model capabilities)

## Выбор моделей (исследование 2026-02-17)

### Video — по типу контента
| Задача | Модель | Почему |
|--------|--------|--------|
| Motion + continuity | **Kling O3 Standard** | Multi-shot ×6, встроенные transitions |
| Физика (жидкости, разрушение) | **Kling v3 Standard** | Лучшая физика объектов |
| Бюджет/итерации | **Grok Imagine / Wan 2.6** | Дёшево, быстро |
| Talking head / lip sync | **Veo 3.1** | Лучший lip sync |
| Минимум затрат | **Vidu Q3 Turbo** | Самый дешёвый |

### Image — по задаче
| Задача | Модель | Почему |
|--------|--------|--------|
| Старт-кадр (реализм) | **Nano Banana Pro** | Реализм + img2img edit |
| Img2img editing | **Flux Kontext Pro** | Локальные правки, трансформации |
| Text overlay в изображении | **Recraft V3** | SOTA text rendering |
| Массовая генерация | **Seedream V4** | Дёшево |
