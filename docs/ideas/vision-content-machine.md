# Vision: Trend-Reactive Content Machine

## North Star
Автоматически создавать YouTube-каналы и наполнять их видео.
Канал за 3 месяца набирает 10M просмотров и быстро проходит порог монетизации (3K subs).

## Целевые метрики
- $15K MRR суммарно
- Lifetime канала: 3-6 месяцев
- ~35 каналов параллельно
- 3 ролика/день на канал (90/мес)
- CU ≤ $1.00 (cost per published unit) — TODO: верифицировать после тестов

## Unit Economics
- YouTube Shorts RPM: $0.03-0.10 за 1000 views (реалистично $0.05)
- 10M views/month/канал = ~$500 revenue

## Full Architecture
```
TREND DETECTOR (24/7)
  - TikTok trending sounds/hashtags (1-6ч signal)
  - X/Twitter trending topics (1-2ч signal)
  - Google Trends Realtime (15мин signal)
  - Reddit Rising (2-4ч signal)
  ↓
STRATEGY AGENT
  - Какой канал, какой формат, какой стиль
  - Фильтр: подходит под ниши? Можно сгенерить? Растёт или спадает?
  ↓
PRODUCER AGENT (LangGraph agent с tools)
  - Набор инструментов: generate_image, edit_image, generate_video, compose, overlay, audio
  - Сам решает какие tools использовать и в каком порядке
  - Оценка: vision model проверяет качество
  - Retry/fallback при плохом результате
  ↓
PUBLISHER
  - Upload на нужный канал
  - Title, description, tags, thumbnail
  - Scheduling
  ↓
ANALYTICS
  - Что зашло, что нет
  - Фидбек в Strategy + Producer для обучения
```

## Цепочка распространения тренда
```
TikTok/X (часы) → Reddit/Memes (4-8ч) → YouTube Shorts (12-48ч) → Mainstream (3-5 дней)
```
Нужно ловить на стадии TikTok/X, публиковать до YouTube-пика.

## Критические риски
1. YouTube давит AI-контент — неконтролируемый риск
2. 10M views/month на канал — нужно доказать на одном
3. 35 Google-аккаунтов параллельно — operational + ban risk
4. RPM может упасть при изменении revenue share
5. Reject rate 35% оптимистичен для автономной генерации (реально 50-60% на старте)

## Phasing
1. **Producer Agent** ← FOCUS NOW
   - Получает концепцию канала
   - Генерит ролики автономно
   - LangGraph + tools
2. **Analytics loop** — агент учится на результатах
3. **Trend Detector** — real-time мониторинг трендов
4. **Publisher** — автоматическая публикация
5. **Strategy Agent** — мульти-канальное управление
6. **Scale** — 35+ каналов на автопилоте

## Банк идей для каналов
Источник: Google Sheets "Идеи для коротких видео"

### AI-generable (приоритет для агента)
- Smash or pass: знаки зодиака — совместимость, хук "Овен smash or pass"
- Гороскопы — что ждёт сегодня/на неделе
- Нарезка еды — залипательная резка с неожиданными внутренностями
- Пресс (давим предметы) — фирменная заставка
- Смешивание красок — загадка "какой цвет получится?", CTA "угадал?"
- Космические катастрофы — "если вместо Солнца...", завораживающий визуал
- Лабиринт — "жми паузу и проходи", интерактив
- Мат задачки/ребусы — "99% не могут решить", ответ в комментах
- Найди отличия — 2 картинки, последнее отличие очень сложное
- Падающие предметы — падение с высоты, пасхалки
- Сюжет книги/фильма за 30с — провокационный плохой пересказ

### Сложнее для AI (текст/голос/реалистичные люди)
- Слэнгтюб — слово + перевод, нужен голос
- Завтрак в стиле Х — картинки + текст
- Экспресс-упражнения — реалистичные люди
- Заносы на слотах — специфичная анимация
- Скретчер — вскрытие карт
- Таймлапс уборки — проще купить донорское видео

### Engagement паттерны из идей
- Загадка/вопрос → ответ в комментах (ребусы, краски, отличия)
- "X% не могут..." → провокация на просмотр
- Пауза/интерактив → увеличивает watch time
- Неожиданный результат → пересмотры
- Фирменная заставка → узнаваемость канала
