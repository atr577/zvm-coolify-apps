# Типы хуков для YouTube Shorts

## Формула хука

**Hook = Visual + Text + Audio**

Все три элемента одновременно — максимальный эффект. 80% зрителей смотрят без звука, поэтому visual + text обязательны.

**Тайминг:** 1.5-2.5 секунды на доставку хука. Не больше.

---

## 3 базовые формулы

### 1. Pattern Interrupt
Неожиданный элемент, ломающий автопилот скроллинга.

- Резкое движение, смена цвета, контраст
- Открытие с середины действия без контекста
- Противоречие ("Я стал зарабатывать больше, когда перестал постить каждый день")
- Необычные ракурсы, быстрые смены кадра

**Данные:** +23% retention в среднем. Работает через периферийное зрение — мозг замечает аномалию до сознательной обработки.

**Лучше всего для:** Entertainment, comedy, визуальный контент.

### 2. Direct Promise
Конкретное обещание результата с цифрами.

- "Эта правка за 5 секунд удвоила watch time"
- "Освой J-cut за 30 секунд"
- Чёткая трансформация

**Лучше всего для:** Tutorial, tech, образовательный контент.

### 3. Question Hook
Эксплуатация информационного разрыва — мозг компульсивно ищет ответ.

- Идентификация боли ("Почему ваши Shorts умирают на 40% watch time?")
- Провокация ("А что если субтитры убивают ваш retention?")
- Инсайдерское знание

**Данные:** Open loops дают +32% watch time.

**Лучше всего для:** Educational, business, нишевый контент.

## Комбинирование хуков

Самые виральные Shorts используют **layered approach** — несколько формул одновременно:

- Pattern Interrupt + Question Hook
- Direct Promise + Visual Proof
- Contradiction + Promise

Многослойные хуки задействуют несколько когнитивных систем одновременно.

---

## Антипаттерны (убивают retention)

1. **Slow build** — контекст и предыстория в первых секундах = смерть
2. **Generic greeting** — "Hey guys, welcome back" = мгновенный swipe
3. **Buried moment** — сильный момент на 10+ секунде, до него никто не досмотрит
4. **Clickbait mismatch** — обещание в хуке ≠ содержание = потеря доверия
5. **Bait-and-switch** — работает один раз, потом алгоритм наказывает

---

## Применение к визуальному контенту (без голоса)

Для контента типа REGGY (satisfying, процессы, AI-видео):

1. **Visual Pattern Interrupt** — первый кадр ДОЛЖЕН быть самым ярким/необычным
2. **Text overlay** — 3-6 слов, высокий контраст, benefit-driven
3. **Результат в начале** — показать конечный результат, потом процесс (reverse hook)
4. **Цветовой контраст** — яркий цвет на нейтральном фоне в первом кадре
5. **Движение с первого кадра** — никаких статичных заставок
