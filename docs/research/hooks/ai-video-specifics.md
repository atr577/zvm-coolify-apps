# AI-Generated Video — специфика для YouTube Shorts

## Текущий ландшафт (2025-2026)

### YouTube vs AI-контент
- **Июль 2025:** YouTube ужесточил правила Partner Program для "mass-produced" repetitive видео
- Чисто AI-generated "fluff" → пенализация
- Оригинальные концепции с AI-ассистом → ОК
- **Ключ:** контент должен быть **оригинальным по концепции**, AI — инструмент производства

### Что значит "mass-produced repetitive"
- Одинаковая структура + одинаковые промпты + минимальная вариация = красный флаг
- Сотни видео с одним шаблоном без творческого вклада
- Контент, который ничем не отличается от тысяч аналогов

## Что работает для AI-видео

### Гибридный подход (рекомендуется)
- **AI делает:** шаблоны, генерацию визуала, редактирование, captions, музыку
- **Человек делает:** концепцию, tone, selection (модерацию), storytelling angle
- Результат: consistent quality + creative originality

|---|--------|-------------|------------|

### Для REGGY конкретно
- **Before/After Transformation** — главный формат. Показать результат → процесс → результат
- **Micro Twist** — процесс идёт обычно, а результат неожиданный
- **Pure Visual Satisfaction** — процесс сам по себе залипательный (не в списке, но наша ниша)

## Производственные преимущества AI

1. **Batch production** — один концепт → 10-20 вариаций за один запуск
2. **A/B testing** — 3 разных хука для одного видео, тест на аудитории
3. **Consistency** — одинаковый стиль и quality across серий
4. **Speed** — от концепта до готового видео за минуты, не дни
5. **Cost** — $1-4 за видео vs $50-500 за ручное производство

## Ограничения и риски

### Authenticity gap
- "Authentic" контент перформит на 60% лучше "polished"
- Чисто AI-видео могут выглядеть "слишком чисто"
- **Решение:** добавлять элементы "несовершенства", текстуры, органичные переходы

### Repetitiveness detection
- YouTube умеет определять повторяющиеся паттерны
- **Решение:** вариативность в промптах, стилях, цветовых схемах
- Каждое видео должно быть визуально уникальным

### AI ASMR тренд (2025-2026)
- Новая волна: AI генерирует "физически невозможные" сценарии
- Примеры: резка стеклянных фруктов, намазывание "джема из самоцветов"
- Уникальные сенсорные триггеры, которые невозможны в реальности
- **Прямо релевантно для REGGY** — AI может создать то, что камера не снимет

## Рекомендуемый workflow для AI Shorts

```
1. Выбрать 1-2 формата
2. Составить 10-20 тем в нише
3. AI генерирует скрипты и визуал по формату
4. Batch-создать контент на неделю/месяц
5. A/B тестировать хуки
6. Амплифицировать победителей
7. Итерировать на основе метрик
```
