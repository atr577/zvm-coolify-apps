# Алгоритм YouTube Shorts — метрики и распределение трафика

## Модель распределения: Explore → Exploit

YouTube использует двухфазное тестирование:

### Phase 1: Explore (seed audience)
- Каждый Short показывается маленькой целевой группе
- Группа подбирается по типу контента (тема, формат, ниша)
- Алгоритм анализирует реакцию seed-аудитории

### Phase 2: Exploit (расширение)
- Если seed-аудитория хорошо вовлекается → расширение на более широкую аудиторию
- Если нет → алгоритм ОСТАНАВЛИВАЕТ продвижение
- Тестирование идёт на сотнях тысяч показов

**Вывод:** Хук определяет, пройдёт ли видео Phase 1. Без хорошего хука видео никогда не получит широкий охват.

## Ключевые метрики

### 1. Viewed vs Swiped Away (главная метрика)

Процент зрителей, которые **посмотрели** Short vs тех кто **свайпнул** дальше.

| Уровень | Viewed % | Swipe Away % | Результат |
|---------|----------|--------------|-----------|
| Отлично | 80%+ | <20% | Агрессивное продвижение |
| Хорошо | 75-80% | 20-25% | Расширенная дистрибуция |
| Нормально | 70-75% | 25-30% | Умеренная дистрибуция |
| Слабо | 50-70% | 30-50% | Ограниченный охват |
| Плохо | <50% | >50% | Алгоритм останавливает |

**Измеряется в первые 1-2 секунды.** Это прямой показатель качества хука.

### 2. Retention Rate (удержание)

| Метрика | Target | Описание |
|---------|--------|----------|
| Intro retention | >70% | % досмотревших первые 3 сек |
| Average completion | >60% | % от полного видео |
| Отличный retention | 80-90% | Топ-перформеры |
| Критический | <50% | Алгоритм считает "skippable" |

**50-60% drop-off происходит в первые 3 секунды.**

### 3. Average View Duration (AVD)

- Среднее время просмотра в секундах
- Может превышать 100% длительности видео (rewatches)
- **Rewatches — сильный сигнал** для алгоритма
- Loop-видео (конец → начало) значительно поднимают AVD

### 4. Engagement (вторичные сигналы)

- Likes, comments, shares
- Shares — самый сильный сигнал из трёх
- Comments влияют на seed audience selection для следующих видео

## Изменения 2025

### Новое определение views (с 31 марта 2025)
- **View** = любой старт воспроизведения или replay (нет минимума по времени)
- **Engaged View** = реальное взаимодействие (просмотр beyond initial seconds + interactions)
- Общее количество views выросло ~на 30%, но engaged views остались прежними
- Монетизация и YPP eligibility привязаны к **engaged views**

### Длительность до 3 минут (2025)
- Shorts теперь до 3 минут (было 60 сек)
- Но оптимальная длительность НЕ изменилась — 15-35 сек по-прежнему лучше всего

---

## Оптимальная длительность

| Тип контента | Sweet spot | Retention |
|--------------|-----------|-----------|
| Quick tips / hacks | 15-20 сек | 85-95% |
| Tutorial / how-to | 25-40 сек | 70-80% |
| Entertainment | 18-28 сек | 75-85% |
| Behind-the-scenes | 30-45 сек | 65-75% |
| Satisfying / process | 15-30 сек | 80-90% |

**Исследование 35B просмотров:** пики перформанса на **13 секунд** и **60 секунд**.

**После 45 секунд retention падает значительно.**

## Формат и визуал

| Элемент | Рекомендация | Данные |
|---------|-------------|--------|
| Аспект | 9:16 (vertical) | Обязательно |
| Captions | Burned-in, word-by-word | +15-25% retention |
| Visual cuts | Каждые 2-4 сек | Топ-перформеры |
| Петля (loop) | Конец → начало seamless | AVD >100% |
| Mobile-first | 95%+ смотрят на телефоне | Текст должен быть крупным |

---

## Consistency Effect

Каналы, публикующие **200+ Shorts**, показывают стабильный рост просмотров со временем.

Рекомендуемая частота: **3-5 Shorts в неделю** минимум.

---

## Динамика метрик по жизненному циклу Short

```
0-2 сек:  Viewed vs Swiped Away → определяет пройдёт ли seed test
2-5 сек:  Intro retention → закрепляет внимание
5-15 сек: Mid-roll retention → пейсинг и visual variety
15+ сек:  Completion → payoff и satisfaction
End:      Loop/replay → AVD boost, сильный алгоритмический сигнал
```

Каждый этап — отдельная "воронка". Провал на любом = потеря на всех следующих.
