# Реальные кейсы каналов — satisfying / faceless / AI контент

**Дата:** 2026-02-18

---

## 1. Sand Tagious (kinetic sand ASMR)

**Формат:** Нарезка и формовка кинетического песка. Без голоса, без лица. Чистый visual + sound.

| Метрика | Значение |
|---------|----------|
| Subscribers | 7.5M |
| Total views | 3.36B |
| Videos | 882 |
| Avg views/video | 106K |
| Posting frequency | 3 раза/неделю |
| Like rate | 0.34% |
| Comment rate | 0.03% |
| Trend | Нисходящий |

**Что видно:**
- Канал на **спаде**. 882 видео, avg 106K views — но недавние видео собирают 5.5K-110K, медиана сильно ниже средней
- Like/comment rate крайне низкие — подтверждает гипотезу: satisfying-контент побеждает retention/replay, не engagement
- 3.36B total views на 7.5M subs = ~448 views/sub — очень высокий ratio (discovery-driven, не subscriber-driven)
- **Урок:** satisfying-ниша — discovery-first. 74% Shorts views идут от non-subscribers. Рост через алгоритм, не через подписную базу
- **Урок:** даже крупные каналы в этой нише деградируют без эволюции формата

**Риск для REGGY:** monotonous формат = diminishing returns. Нужна **вариативность** с первого дня.

## 2. Bella's ASMR (AI-generated ASMR)

**Формат:** AI-generated ASMR с визуальными триггерами и ролеплей-сценариями. Long-form (20+ мин).

| Метрика | Значение |
|---------|----------|
| Subscribers | 0 → 150K за 3 месяца |
| Monthly views | 2-3M |
| Monthly revenue | $4K-$8K (ads) |
| Posting frequency | 3 видео/неделю |
| Video length | 20+ мин |
| Production time | <2 часов (vs 8 часов traditional) |

**Что видно:**
- AI-generated контент **работает** в ASMR нише — 150K за 3 месяца = быстрый рост
- **Но это long-form**, не Shorts. RPM long-form ASMR: $10-11 vs Shorts $0.03-0.07
- Community loyalty: отвечают на комменты за 24 часа, инкорпорируют feedback
- Consistent schedule на тех же днях/времени

**Применимость к REGGY:**
- Подтверждает: AI-generated satisfying контент принимается аудиторией
- НО: наш формат Shorts, не long-form. Revenue model кардинально другая
- **Урок:** consistency + community ≥ quality каждого отдельного видео

## 3. @InTheNow / Kapwing (faceless Shorts case study)

**Формат:** Faceless Shorts про гимнастику, AI-voice, news-driven контент.

| Метрика | Значение |
|---------|----------|
| Timeline | 157 дней (5 мес) |
| Videos | 60 (58 Shorts + 2 long) |
| Subscribers | 1,200 |
| Total views | 1.1M |
| Avg views/video | 19K |
| Best video | 216K views |
| Watch hours (90 дней) | 37 часов |
| Shorts views (90 дней) | 500K |

**Что видно:**
- **Не прошёл монетизацию.** 1.1M views, но только 500K Shorts views за 90 дней (нужно 3M) или 37 watch hours (нужно 3,000)
- AI voice "lack of inflection" = плохо для long-form. Для визуального satisfying = не проблема (нет голоса)
- YouTube **временно заблокировал** канал за "spam, scams, or other deceptive practices" — AI content flag
- Поиск работает: видео по search-запросам ("Is Simone Biles injured?") давали всплески
- Видео набирали основные views в первую неделю, но bump через несколько недель тоже был

**Применимость к REGGY:**
- **Монетизация через Shorts — тяжело.** 3M views за 90 дней = 1M/мес = ~33K views/день
- При 60 видео/мес и avg 19K views = 1.14M. Не дотягивает
- Нужно либо: (a) вирал-хиты >100K, (b) больше видео, (c) higher avg views
- **Риск AI-бана** — реальный, нужно учитывать

## 4. Tony Piloseno / @tonesterpaints (paint mixing TikTok → YouTube)

**Формат:** Реальное смешивание краски в магазине Sherwin-Williams. Psychedelic swirls + добавки (глиттер, светящиеся палочки).

| Метрика | Значение |
|---------|----------|
| TikTok followers | 1.4M+ |
| YouTube | Малый канал (TikTok-first) |
| Вирусность | Сотни тысяч лайков на TikTok |
| История | Уволен из Sherwin-Williams за видео |

**Что видно:**
- Paint mixing = **proven viral format**. 1.4M followers на TikTok
- Контент работает on camera (реальные краски), значит AI-generated версия тоже имеет шансы
- Cross-platform: TikTok → YouTube → Instagram. Один контент, три платформы
- **Уволен** за это — значит реальный paint mixing требует ресурсов/рисков. AI-генерация = advantage

**Применимость к REGGY:**
- Подтверждает: paint mixing = устойчивый спрос
- AI-версия убирает логистику (краски, мастерская, уборка)
- НО: "authenticity" реального процесса vs "чистота" AI — открытый вопрос

## 6. Паттерны роста faceless-каналов

| Этап | Timeline | Что происходит |
|------|----------|----------------|
| 0-30 видео | 1-2 мес | "Прогрев" — алгоритм изучает канал, views низкие |
| 30-40 видео | 2-3 мес | **Traction point** — алгоритм начинает рекомендовать |
| 40-100 видео | 3-5 мес | Рост ускоряется если формат найден |
| 100+ видео | 5+ мес | Стабильный поток, viral outliers |

**Ключевые факты:**
- Faceless каналы растут **в 2-3 раза медленнее** face-каналов
- Но satisfying/ASMR — исключение: growth rate сравним из-за высокой discovery rate
- Daily posting = 3x growth vs weekly
- Видео 30-40 — критическая масса для алгоритма. До этого — "инвестиционная" фаза
- Реалистичный timeline 0 → 100K subs: **12-14 месяцев** при daily posting

## 7. Выводы для REGGY

### Подтверждено кейсами
1. **Satisfying = discovery-first.** 74% views от non-subscribers. Алгоритм > подписная база
2. **AI-контент работает** — Bella's ASMR, AI ASMR тренд. Аудитория не отвергает
3. **Paint mixing — proven format.** tonesterpaints (1.4M TikTok), 32B views в нише
4. **Monotonous формат деградирует.** Sand Tagious на спаде после 882 видео
5. **Монетизация Shorts — тяжело.** RPM $0.03-0.33, vs long-form $10-11

### Риски, подтверждённые кейсами
1. **AI content flag** — Kapwing канал заблокировали временно
2. **Repetitive content** — YouTube rules 2025 + Sand Tagious decline
3. **Монетизация** — 10M views/90 дней = высокий порог для Shorts-only
4. **Format fatigue** — один формат = diminishing returns через 6-12 мес

### Рекомендации
1. **Вариативность с первого дня** — 3-4 подформата paint mixing, не один
2. **Cross-platform** — один контент → YouTube + TikTok + Reels
3. **30-40 видео — минимум** перед оценкой результатов (прогрев алгоритма)
4. **Без музыки = больше RPM** (100% vs 50% при 1 треке)
5. **Target: 55K+ avg views** для достижения 10M/90 дней при 60 видео/мес
6. **Consider long-form** — satisfying compilations для watch hours + RPM
