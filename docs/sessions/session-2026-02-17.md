### Ключевые решения

- **Три фазы агента:** Research (~$0.05-0.10/концепт) → Human Review → Production (~$1.83/видео)
- **Research один раз, production многократно** — config переиспользуется для 60+ видео
- **Hybrid архитектура:** StateGraph как backbone (предсказуемый pipeline) + LLM decision nodes в ключевых точках
- **Knowledge base первичен:** агент сначала проверяет KB, потом web search — не ищет то что уже знаем
- **Гипотезы из таблицы идей** — research agent валидирует, не копирует слепо

### Ключевые находки (research)

- **70% completion rate** — порог виральности на обеих платформах (TikTok + YouTube)
- **CTR не имеет значения** для Shorts (autoplay в ленте)
- **Completion > likes > shares** — ранжирование сигналов алгоритма YouTube
- **15-30с** — sweet spot для satisfying контента
- **AI content policy (июль 2025):** "inauthentic content" — если все видео одинаковый шаблон → флаг
- **Наш ролик: 40% retention** — ниже порога 70%, алгоритм не распространяет
- **Reverse = anti-hook:** первый кадр (uniform цвет) визуально пустой, убивает retention

### Аудит промптов vs research

| Расхождение | Наш эксперимент | Research рекомендует |
|---|---|---|
| Длительность | 8с | 15-30с для satisfying |
| Первый кадр reverse | Uniform flat color (пустой) | Визуально плотный, 3+ элементов |
| Seamless loop | Нет (audio обрывается) | +65% rewatches |
| CTA на reverse | "guess color" (цвет уже виден) | Должен соответствовать формату |
| CTA позиция | Top center | Риск UI overlay (288-380px от верха) |
