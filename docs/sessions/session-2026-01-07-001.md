# Сессия разработки: Viral Video Generator
**Дата:** 2026-01-07
**Проект:** Автоматизация создания вирусных видео для Instagram/TikTok/YouTube

---

## 📋 Краткое содержание

Разработана полноценная платформа для автоматической генерации коротких вирусных видео с использованием AI (GPT-5 + KLING v2.1) через unified API провайдера AIMLAPI.

---

## 🎯 Исходная задача

Автоматизировать создание коротких виральных видео для:
- Instagram Reels
- TikTok
- YouTube Shorts

**Требования:**
- Использовать ChatGPT/GPT для генерации контента
- Использовать KLING AI для генерации изображений и видео
- Workflow с checkpoints и самопроверкой на каждом этапе
- Публикация на социальные платформы

---

## 🔄 Workflow генерации (8 этапов)

### 1. Story Generation (Генерация сюжета)
**Input:** Structured форма от пользователя
- Тема/ниша
- Целевая аудитория
- Настроение (8 вариантов)
- Ключевые элементы
- Длительность (5 или 10 сек)
- Целевые платформы
- Дополнительные указания

**Output:** JSON с полями:
```json
{
  "concept": "концепция видео",
  "theme": "тема/жанр",
  "target_audience": "целевая аудитория",
  "hook": "захватывающий hook для первых 3 секунд",
  "emotional_trigger": "эмоциональный триггер",
  "viral_potential": "почему это будет вирально"
}
```

**Validation:** Автоматическая проверка виральности, ясности, hook

### 2. Description Generation (Детальное описание)
**Input:** Story data

**Output:** 3 таблицы в JSON:
- `model`: appearance, clothing, pose, expression
- `auto`: brand_model, color, features, condition (если применимо)
- `composition`: location, lighting, camera_angle, background, mood

**Validation:** Соответствие сюжету, достаточность деталей

### 3. Image Prompt Generation
**Input:** Description data

**Output:** Оптимизированный английский промпт для KLING (50-150 слов)

**Validation:** Соответствие описанию, техническая корректность

### 4. Image Generation
**Input:** Image prompt

**Output:** URL изображения (первый кадр видео)

**Технические детали:**
- Используется KLING text-to-video с duration=5
- Возвращается URL видео (можно экстрагировать первый кадр)
- Aspect ratio: 16:9
- Mode: standard

**Validation:** Соответствие промпту, качество композиции

### 5. Scenario Generation
**Input:** Image URL + Description

**Output:** JSON с полями:
```json
{
  "title": "цепляющее название (до 60 символов)",
  "description": "описание для поста (до 150 символов)",
  "scene_direction": "режиссерские указания",
  "hashtags": ["хештег1", "хештег2", ...],
  "duration_seconds": 5
}
```

**Validation:** Соответствие концепции, динамика, реализуемость

### 6. Video Generation
**Input:** Image URL + Scenario

**Output:** URL финального видео

**Технические детали:**
- KLING image-to-video
- Duration: 5 или 10 сек
- Mode: standard
- Поддержка camera_control и motion_brush (опционально)

**Validation:** Соответствие сценарию, качество, отсутствие артефактов

### 7. Platform Adaptation
**Input:** Scenario + список платформ

**Output:** Оптимизированные версии для каждой платформы:
```json
{
  "instagram": {
    "title": "...",
    "description": "...",
    "hashtags": "..."
  },
  "tiktok": { ... },
  "youtube": { ... }
}
```

**Validation:** Соответствие специфике платформ

### 8. Publishing
**Input:** Video URL + Platform adaptations

**Output:** Статусы публикации на каждой платформе

**Поддержка:**
- Instagram API (требует Business Account + токен)
- TikTok API (OAuth)
- YouTube API (OAuth)

## 🔑 Ключевые решения

### 1. Выбор API провайдера: AIMLAPI
**Проблема:** Нужен доступ к GPT-5 и KLING через единое API

**Рассмотрены:**
- OpenAI API (нет KLING)
- PiAPI (есть KLING, нет GPT-5)
- Atlas Cloud (ограниченный доступ)
- fal.ai (нет KLING)
- OpenRouter (нет KLING)
- **AIMLAPI ✅** - unified доступ к GPT-5 + KLING v2.1

**Преимущества AIMLAPI:**
- Единый API ключ
- OpenAI-совместимый endpoint для GPT
- Нативная поддержка KLING text-to-video и image-to-video
- Документация и примеры

### 2. Story Generation: Structured форма
**Было:** Простое текстовое поле "custom_input"

**Стало:** 7 полей с конкретными параметрами:
- Theme (текст)
- Target audience (текст)
- Mood (dropdown: вдохновляющее, смешное, мотивирующее, ...)
- Key elements (текст)
- Duration (radio: 5 или 10 сек)
- Platforms (checkboxes: instagram, tiktok, youtube)
- Additional notes (textarea)

**Преимущество:** GPT получает структурированный контекст для более точной генерации

### 3. KLING Image Generation
**Проблема:** KLING в основном делает видео, не ясно про text-to-image в API

**Решение:**
- Используем `text-to-video` с duration=5 секунд
- Возвращаем URL видео
- Frontend может показать preview
- В будущем: добавить экстракцию первого кадра или использовать DALL-E

### 4. Unified AIMLAPI Client
**Архитектура:**
```python
class AIMLAPIClient:
    # GPT методы
    async def chat_completion(messages, model, temperature, response_format)
    async def generate_text(prompt, model, temperature)
    async def generate_json(prompt, system_prompt, temperature)

    # KLING методы
    async def create_video_task(task_type, prompt, image_url, duration, ...)
    async def get_video_task_status(task_id)
    async def wait_for_video(task_id, max_wait_time, poll_interval)
    async def generate_video_from_text(prompt, duration, aspect_ratio, mode)
    async def generate_video_from_image(image_url, prompt, duration, mode)

    # Internal
    async def _make_request(method, endpoint, data, params, max_retries)
```

**Features:**
- Retry logic с exponential backoff (3 попытки)
- Rate limit handling (429 status)
- Timeout: 300s total, 10s connect
- Async polling для KLING видео
- Error handling: AIMLAPIError, RateLimitError, ModelNotFoundError

## 🔧 Технические детали

### Retry Logic
```python
for attempt in range(max_retries):
    try:
        # ... make request
    except httpx.HTTPStatusError as e:
        if attempt < max_retries - 1:
            wait_time = 2 ** attempt  # 1s, 2s, 4s
            await asyncio.sleep(wait_time)
        else:
            raise AIMLAPIError(...)
```

### KLING Video Polling
```python
async def wait_for_video(task_id, max_wait_time=900, poll_interval=10):
    elapsed = 0
    while elapsed < max_wait_time:
        result = await get_video_task_status(task_id)
        status = result.get("status", "").lower()

        if status in ["completed", "succeeded", "success"]:
            return video_url
        elif status in ["failed", "error"]:
            raise AIMLAPIError(...)

        await asyncio.sleep(poll_interval)
        elapsed += poll_interval

    raise TimeoutError(...)
```

## 🎓 Уроки и инсайты

### 1. Structured Input > Free Text
Для AI генерации лучше давать структурированный ввод с конкретными полями, чем просить "опиши что хочешь"

### 2. Self-Validation критична
Автоматическая валидация на каждом этапе позволяет:
- Отловить проблемы до показа пользователю
- Дать конкретные рекомендации
- Сэкономить токены на регенерации

### 3. Unified API Provider экономит время
Вместо интеграции 2+ API (OpenAI + PiAPI), одна интеграция (AIMLAPI) покрывает все нужды

### 4. Async + Retry = Must Have
Для генеративных AI задач:
- Всё должно быть async
- Retry logic обязателен
- Polling для long-running задач
- Timeout на всё

### 5. Checkpoints = User Control
Пользователь должен утверждать результат на каждом значимом этапе, а не только в конце
